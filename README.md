# MLCapstone_Proj001
Detecting anomalous behavior in financial markets is a longstanding challenge in quantitative finance. Traditional methods often rely on volatility models, statistical process control, or machine learning techniques operating on handcrafted features. However, financial time series possess path-dependent characteristics that are difficult to summarize using pointwise statistics.
Path signatures, originating from rough path theory, provide a feature representation that captures the geometric structure of sequential data through iterated integrals. Recent research demonstrates that signature features can serve as universal representations of paths and can be used for novelty detection, hypothesis testing, and one-class classification tasks. This project will build on the ideas presented in the recent paper "Novelty Detection on Path Space" by Gasteratos et al. (https://arxiv.org/pdf/2512.03243).
Specifically, this project aims to apply these methods to publicly available market data to detect unusual price movements and market regime changes.
The historical event detection component will evaluate whether anomaly scores can effectively identify major market disruptions, including the 2020 COVID crash, the 2021 meme-stock event, the 2022 crypto crash, and the 2023 banking crisis. The project also aims to detect transitions between bull and bear markets, as well as between periods of high and low volatility.
The data will be sourced from public APIs, including daily price data from Yahoo Finance.
